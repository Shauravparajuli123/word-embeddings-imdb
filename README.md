# Word Embeddings Comparison (IMDb Dataset)

## Models Implemented
- Word2Vec (CBOW & Skip-Gram)
- FastText
- GloVe (Pretrained)

## Dataset
IMDb Movie Reviews Dataset (~50K reviews)

## Tasks Completed
- Training embeddings on full dataset
- Cosine similarity analysis
- Top-10 similar words extraction
- TSNE visualization

## Key Observations
- Skip-Gram captures better semantic relationships
- FastText handles subwords (e.g., "goodbut")
- GloVe captures global context
- Word embeddings capture context similarity, not sentiment polarity

## How to Run
Open the notebook in Google Colab and run all cells.
